## Current behavior

Add and Shop show the actual group name and a common leading Settings button. Account identity, sign-in, group creation, pending invitations, invitation management and sign-out live in Settings. Incoming invitations request that sheet while respecting existing editor/capture presentation boundaries.

Manual Add submits the entered row from its form without a second review, preserving unrelated draft rows. A valid finished dictation automatically interprets and shows Confirm/Edit for a complete proposal; Confirm submits only that proposal, while Edit exposes local recovery controls. Unique exact store names resolve automatically. New typed names retain explicit creation intent; genuine ambiguity offers an inline choice. Silence, cancellation and backgrounding cannot interpret old text. An unavailable model presents manual entry and preserves access to saved text. Store voice query remains independent of Apple Intelligence.

Forms use existing canvas/surface/text tokens. Explicit actions use primary capsules, while microphone/edit/remove controls are localized icons with minimum 44-point targets. Selection has both a check and an accessible value. Native cancellation alerts and destructive roles remain. Store/input controls and product rows reflow at accessibility text sizes.
